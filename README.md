# «Аккорд»: каталог занятий и абонементов — КР №4

Бульдин Захар Андреевич, ЭФБО-01-25.

Тема: «JavaScript: интерактивность, DOM, события, формы и валидация».
Основа — собственная КР №3 `kr3-responsive-shop`: сохранены палитра, фотографии,
шрифты, навигация, адаптивная сетка и тема музыкальной школы. Товарами являются
занятия и абонементы. Реализация на чистом JavaScript без библиотек и сборки.

## Запуск

Откройте папку в VS Code и запустите `index.html` через Live Server.
Альтернатива: `python -m http.server 8000` из папки проекта, затем
`http://localhost:8000/index.html` в браузере. Для одинакового localStorage на всех
страницах используйте один адрес и порт. Открытие через file:// возможно, но
сохранение между страницами зависит от браузера — рекомендуется HTTP.

## Структура

- `index.html` — главная и популярные занятия, генерируемые из данных.
- `catalog.html` — все 9 позиций, поиск, категория, наличие, избранное, сортировка.
- `product.html?id=1` — подробности выбранного занятия; неизвестный id обрабатывается.
- `cart.html` — корзина, количество, удаление, промокод и сумма.
- `order.html` — состав заказа и форма заявки.
- `contacts.html` — контакты и форма обратного звонка.
- `css/style.css`, `css/responsive.css` — оформление и адаптивность из КР №3.
- `css/shop.css` — дополнения для каталога и корзины.
- `images/` — локальные фотографии, в том числе WebP 360/720 px.

## JavaScript-файлы

Все файлы подключаются с `defer`: выполняются после разбора HTML в указанном порядке.

| Файл | Назначение |
|---|---|
| `data.js` | Массив `products`, форматирование рублей, безопасное создание элементов |
| `cart.js` | Состояние, проверка localStorage, корзина, количество, скидка и суммы |
| `modal.js` | Быстрый просмотр товара в нативном dialog, фокус и Escape |
| `catalog.js` | Создание карточек, поиск, фильтры, сортировка, избранное и страница товара |
| `validation.js` | Проверки полей, ошибки рядом с полями и имитация подготовки заявки |
| `main.js` | Мобильное меню и запуск функций вывода для текущей страницы |

## Данные и алгоритм

В `products` девять объектов одинаковой структуры: числовые `id`, `price`, `lessons`,
строки `title`, `category`, `image`, `description`, логическое `isAvailable`.
Три направления: гитара, фортепиано и вокал. Для каждого есть пробное занятие,
абонементы на 4 и 8 занятий. Один абонемент недоступен для демонстрации состояния наличия.

Паттерн: данные → обработка массива → DOM → события пользователя → новое состояние → DOM.

Поиск реагирует на `input`, игнорирует регистр и пробелы по краям. Фильтры категории,
наличия и избранного работают одновременно с поиском. Сортировка: исходный порядок,
цена по возрастанию/убыванию, название по русскому алфавиту. `sort()` вызывается на
копии массива. `filter` отбирает позиции, `map` создаёт карточки, `find` ищет товар
по id, `reduce` вычисляет стоимость и среднюю цену. Пустой результат сопровождается
сообщением и кнопкой сброса. Карточки не прописаны вручную в HTML.

## Безопасный вывод и события

Общий помощник `element()` использует `document.createElement`, `textContent` и
`classList.add`. Узлы добавляются через `append`, заменяются через `replaceChildren`.
Пользовательский ввод и localStorage никогда не вставляются через `innerHTML`.
События подключены через `addEventListener`: `click`, `input`, `change`, `submit`,
`reset`, `keydown`. `preventDefault()` отменяет перезагрузку при отправке формы.
`dataset.id` связывает кнопку добавления с товаром.

## Корзина и самостоятельные доработки

- Добавление доступных позиций и удаление. Повторное добавление увеличивает количество.
- Количество — целое число от 1 до 20, ошибочный ввод возвращается к предыдущему значению.
- Сумма рассчитывается через `reduce`, цены берутся из исходного каталога.
- Промокод **АККОРД10** даёт скидку 10% на всю корзину. Скидка округляется до рубля.
  Повторное применение не складывает скидки. Пустой или неверный код снимает скидку.
- Избранное сохраняется и доступно отдельным фильтром.
- localStorage с ключом `akkord-kr4` сохраняет `{cart, favorites, promo}`.
  В корзине хранятся только `{id, quantity}`. При чтении проверяются id, количество,
  доступность и дубликаты. Повреждённый JSON не ломает страницу. При запрете записи
  выводится сообщение, состояние продолжает работать в памяти текущей страницы.
- Быстрый просмотр, названия кнопок, `aria-pressed`, статус наличия, счётчики,
  средняя цена, пустые состояния каталога и корзины.
- Форма показывает состояние подготовки, временно блокирует повторную отправку,
  очищается после успеха. Корзина сохраняется: это демонстрация, заказ на сервере не создаётся.

## Валидация

Имя после удаления пробелов по краям — минимум 2 символа. E-mail проверяется
встроенной проверкой браузера, телефон — 10–15 цифр; допускаются плюс, скобки,
дефисы и пробелы. Согласие обязательно. Ошибки выводятся текстом возле полей,
связаны через `aria-describedby`, устанавливается `aria-invalid`. Фокус переводится
к первому ошибочному полю. Для оформления заказа нужна непустая корзина.
Контактная форма может работать без корзины. `alert()` не используется.

Имитируется задержка 600 мс. ФИО, e-mail и телефон не отправляются и не сохраняются.
Контакты школы учебные. Реального оформления покупки и оплаты нет.

## Проверка и защита

В Chrome проверены 6 страниц на ширинах 360, 430, 768, 1024, 1440 px — 30 сочетаний:
горизонтального переполнения не обнаружено. Проверены поиск, сочетание фильтров,
сортировка, наличие, избранное, диалог, добавление/удаление, изменение количества,
сохранение после перезагрузки, скидка, пустая/неверная/верная форма, повреждённый
localStorage и безопасный текст. Ошибок JavaScript в проверенных сценариях нет.
Старые Lighthouse-отчёты КР №3 не включены: они не относятся к изменённому сайту.

Повторение вручную:

1. В каталоге ввести «фортепиано»: останется 3 позиции. Выбрать гитару — пустой результат.
2. Сбросить, выбрать сортировку по убыванию цены: первым станет абонемент фортепиано за 13 600 ₽.
3. Отметить «Только доступные»: останется 8 позиций.
4. Добавить позицию в избранное, включить фильтр избранного, перезагрузить страницу.
5. Открыть быстрый просмотр, проверить Tab/Shift+Tab и закрыть Escape.
6. Добавить фортепиано на 8 занятий, в корзине поставить 2 и применить АККОРД10:
   27 200 − 2 720 = **24 480 ₽**. Перезагрузить и проверить сохранение.
7. Перейти к оформлению, отправить пустую форму; проверить сообщения. Затем заполнить
   корректно и дождаться демонстрационного подтверждения.
8. Удалить все позиции, проверить пустую корзину и отсутствие кнопки оформления.
9. В Console проверить отсутствие ошибок. Для отладки поставить breakpoint внутри `renderCatalog`, ввести поиск и посмотреть переменные `query` и `result` во вкладке Scope.
